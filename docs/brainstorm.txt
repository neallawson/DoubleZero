  - top down and oblique views of the field.
  - green field with proper white lines in the correct locations.

  - players can be dragged and dropped around the field to new positions.
  - To keep the positions accuracate on multiple devices, we will define a world coordinates system for the field

  - The user will have the ability to zoom in using pinch to zoom and pan using their finger. This should be supported in the web app/browser.
  - The user will at any time be able to "snapshot" the field at that moment. This snapshot creates a "snapshot" record in the database that
  records each player on the field and their position in world coordinates. Other things might be added to this record in the future,

  playboard composition record. We'll want a camera/snapshot icon to create a snapshot. A shapshot name is auto assigned (date/timestamp), and
